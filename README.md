# Titu Das — Personal Portfolio Website

A responsive, single-page personal portfolio built with HTML, CSS, and a small amount of JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout, colors, typography, and responsive design
- `script.js` — mobile menu, active navigation, and current year

## How to open
1. Extract the ZIP file.
2. Open the `titu_portfolio_website` folder.
3. Open `index.html` in a browser such as Chrome.

For editing, open the folder in Visual Studio Code.

## Before submitting
- Verify your university session, education details, and all personal information.
- Add your own profile photo if you want one.
- Add only public contact links you are comfortable sharing.
- Replace or remove any sample project/skill text that does not reflect your actual experience.
- Test on both a desktop and a phone-sized screen.
- Follow your teacher's requirements for file format and report.

## Publish online (optional)
You can publish this static website using GitHub Pages:
1. Create or sign in to a GitHub account.
2. Create a repository and upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's Settings → Pages.
4. Select the deployment source/branch as prompted and save.
5. GitHub will show the published URL when deployment is ready.

The public URL can then be added to a CV, LinkedIn profile, or other profile that supports website links. Publishing settings can change, so follow the current GitHub Pages instructions.

## Notes
This project uses Google Fonts via an external stylesheet. If internet access is unavailable, the page falls back to common system fonts. No database or server is required for this static site.
